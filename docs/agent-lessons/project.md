# 经验：本项目

由 yado_agents 自动维护：自动 review 和代码清理时总结的规则。要作废请到控制台「Agent → 经验」，不要直接改这个文件。

- 测试目标不默认 MainActor，不要在默认参数里调用 @MainActor 类型的初始化方法（默认参数在非隔离上下文求值，会让整个测试目标编译失败）
- 测试里不要把 #require 写进另一个 #require 的参数，先拆成单独的 let 再用（嵌套会让宏递归展开，整个测试目标编译不过）
- 新增 @Model 时，搜出所有逐个列举模型的地方（清空、备份、导入、同步、判断有无数据），一起补上新模型（漏掉判空会把只有新数据的账本当成空账本）
